# 第一部分 认识立陶宛

搬到一个新国家，最先要处理的是签证和住处，但最先应该读的是这一部分。知道这里的冬天有多长、政府机构怎么分工、本地人在意什么，后面每一件事都会顺一些。

## 这一部分回答什么

- 立陶宛在哪，多大，气候怎样，三座主要城市有什么不同
- 哪些历史事件还在影响今天的政策和人们的态度
- 办事时面对的是哪一级政府、哪个机构
- 日常相处里有哪些没人明说的规矩
- 欧盟、申根、北约成员身份，以及中立关系，对住在这里的中国人意味着什么
