# 第四部分 工作、收入与财务

对大多数持工作类居留的人来说，工作是留在这里的前提。这一部分讲怎么找到工作、合同里写了什么、工资为什么到手少了四成，以及剩下的钱怎么管。

## 这一部分回答什么

- 去哪找工作，薪资水平大概多少，招聘广告上的数字是税前还是税后
- 试用期、年假、病假、加班、辞退分别怎么规定
- 丢了工作，居留和失业金怎么办
- 怎么开银行账户，第二、第三支柱养老金要不要参加
- 个人所得税怎么算，每年五月前要做什么
- 想做副业或开公司，选哪种形式
