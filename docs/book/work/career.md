# 求职与职场文化

对持工作类居留的人，工作不只是收入来源，还是居留的依据。这一章讲去哪找工作、薪资怎么谈、面试和办公室里是什么气氛。合同、休假和辞退的规则在下一章[劳动关系与社会保障](employment.md)。

## 先确认你的身份允许做什么

找工作之前先弄清自己这张居留卡对工作的限制，不同类别差别很大：

| 居留类别 | 能不能自由换工作 |
|---|---|
| 欧盟蓝卡 | 头 12 个月换雇主要先获移民局许可，满 12 个月后可自由换 |
| 普通雇佣 | 绑定雇主和岗位。持证满 6 个月后才能申请换雇主 |
| 家庭团聚 | 可以为任何雇主工作，不需要另办许可 |
| 学习类居留 | 本科一、二年级每周最多 20 小时，其他阶段可以全职 |
| 永久居留 | 不受限制 |

细节见[身份、居留与行政](../life/documents.md#换工作)。

人还在国外的话，顺序是：先拿到 offer，雇主在移民局系统里提交担保函，你再申请居留许可。没有雇主担保，工作居留申请开始不了。中国境内目前没有递交点，怎么递交见[从中国递交申请](../life/documents.md#从中国递交申请)。

## 哪些行业在招外国人

**不需要立陶宛语的岗位**集中在这几类：

- **IT 与软件**：产品公司（Vinted、Nord Security、Hostinger、Tesonet 系的公司）和外企的研发中心。
- **金融科技与共享服务中心**：立陶宛是欧盟发放电子货币牌照最多的国家之一，Revolut 的欧盟银行牌照就在这里。北欧银行和美国公司在维尔纽斯设有大型运营和技术中心。
- **生物技术与激光**：Thermo Fisher Scientific 在维尔纽斯有大型研发和生产基地。本地的激光企业（Light Conversion、Ekspla）在超快激光领域有全球份额。
- **工程与制造**：考纳斯自由经济区里的汽车电子厂，以及 Teltonika 这样的本地物联网硬件公司。
- **物流与运输**：立陶宛的公路货运公司雇用大量非欧盟司机，是外籍劳工人数最多的行业。

**需要立陶宛语的**：零售、餐饮服务、公共部门、医疗、教育、法律，以及绝大多数面向本地客户的岗位。

!!! warning "中文不是优势"

    需要中文的岗位非常少。立陶宛与中国的贸易往来有限，没有成规模的中资企业。来之前请把自己定位成「会英语的专业人士」，不要指望靠中文找到工作。

## 去哪找

| 渠道 | 说明 |
|---|---|
| [cvbankas.lt](https://www.cvbankas.lt/) | 本地最大的招聘网站，岗位最全，以立陶宛语为主，可按「英语」筛选 |
| [cvonline.lt](https://www.cvonline.lt/) | 第二大，界面有英文 |
| LinkedIn | 国际公司和 IT 岗位的主战场，猎头也在这里找人 |
| [Work in Lithuania](https://workinlithuania.com/) | 政府机构 Invest Lithuania 办的，专门面向国际人才，全英文，还提供搬迁咨询 |

| [uzt.lt](https://uzt.lt/) | 就业服务局的岗位库，蓝领和基础岗位多 |

IT 岗位很多是通过内推和猎头成交的。把 LinkedIn 的所在地改成 Lithuania，把「Open to work」对猎头打开，会收到不少消息。

## 薪资怎么看

**法律要求招聘广告必须写明薪资或薪资范围。** 这是立陶宛求职市场对求职者最友好的一点，投之前就知道大概给多少。

要注意的是口径：

- 广告和合同上的数字默认是**税前月薪**，写作 bruto，口语叫「ant popieriaus」（在纸上）。
- 税后叫 neto，口语叫「į rankas」（到手）。
- 税前到税后大约打六折。税前 3,000 欧元，到手 1,800 欧元出头。算法见[个人税务与年度申报](tax.md)。
- 谈薪谈的是月薪，不是年薪。没有十三薪的惯例，奖金另说。

2026 年的大致水平：

| | 税前月薪 |
|---|---|
| 最低月薪（MMA） | 1,153 欧元 |
| 全国平均（2026 年第二季度） | 2,628 欧元，到手约 1,595 欧元 |
| 维尔纽斯市平均 | 2,967 欧元，到手约 1,795 欧元 |
| 蓝卡的薪资门槛 | 3,617.10 欧元（清单内的紧缺职业 2,893.68 欧元） |

同样的岗位，立陶宛的薪资低于德国、荷兰，高于波兰以外的多数中东欧国家。生活成本也在同样的位置上。

## 简历和面试

- **简历**：一到两页，英文。不需要照片、年龄、婚姻状况。经历倒序写，每段写做成了什么。Europass 格式能用，但不是必须。
- **求职信**：小公司和非技术岗位有时会看，技术岗位基本不看。
- **流程**：HR 电话沟通，一到两轮技术或业务面试，有的公司加一个带回家做的小任务，最后是和团队负责人聊。整个过程两到四周。
- **会被问到的**：期望薪资（给税前月薪的一个范围）、最快什么时候能入职、居留身份。对最后一个问题如实回答，有经验的雇主知道蓝卡怎么办。
- **可以问对方的**：是否协助办理居留和搬迁，是否提供商业医疗保险，远程办公的政策，试用期多长。

对还在国外的候选人，全程视频面试是常态。

## 办公室里

- **扁平**。直呼其名，包括对 CEO。立陶宛语里有「你」（tu）和「您」（jūs）之分，同事之间很快就会用 tu。
- **直接**。反馈不绕弯子，会议上直接说不同意。这不是针对你。
- **准时下班**。六点以后办公室基本没人，加班不是美德。法律对加班有上限和加价规定。
- **假期是真的**。每年至少 20 个工作日年假，很多人夏天连休两三周，期间不回邮件。
- **午饭**。十二点前后，很多餐厅有工作日午市套餐（dienos pietūs），一汤一主菜。带饭的人也不少。
- **远程和混合办公**很普遍，IT 公司多数每周只要求到岗一两天。
- **社交**。夏季团建和圣诞聚会是一年两次的大事。平时同事之间不太约饭，周五下班后喝一杯算是亲近的表示。

常见的福利：商业医疗保险、额外的带薪假、运动卡、第三支柱养老金的雇主缴存、搬迁补贴、期权。

## 学历和职业资格

- **学术学历认证**：找高等教育质量评估中心 SKVC。申请蓝卡时，不受监管的职业由雇主说明你的资格，法律没有要求先做 SKVC 认证；受监管的职业要先经主管机构认可。见[大学与终身学习](../people/learning.md)。
- **受监管职业**：医生、护士、药剂师、教师、律师、建筑师等需要职业资格认可，并且实际上都要求立陶宛语。
- **不受监管的职业**：程序员、设计师、市场、销售等，雇主认可就行。

## 远程为国外雇主工作

人住在立陶宛、给境外公司远程工作，会同时牵扯居留依据和税务居民身份两个问题。立陶宛没有专门的「数字游民签证」。

如果你的居留依据是家庭团聚或永久居留，工作权没有问题，剩下的是怎么合规报税，通常要注册个体经营，见[创业与经营](business.md)。如果居留依据是在立陶宛的雇佣，那份雇佣必须真实存在。
