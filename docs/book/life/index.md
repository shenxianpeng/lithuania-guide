# 第二部分 建立日常生活

这一部分是落地手册。居留卡、住址、住处、吃饭、出行、手机，这六件事接上了，生活才算开始运转。

## 这一部分回答什么

- 我的居留许可是哪一类，能做什么，什么时候续，以后怎么转永居
- 怎么找房、签合同，冬天的暖气账单为什么是夏天的三倍
- 去哪买菜，中国调料在哪买，网购的东西去哪取
- 公交怎么坐，中国驾照能不能用，值不值得买车
- 手机卡、宽带、电子签名怎么办，装哪些 App
- 周末和假期怎么过，去哪里认识人
