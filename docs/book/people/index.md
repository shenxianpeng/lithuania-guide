# 第三部分 健康、家庭与学习

这一部分讲不那么紧急、但决定你能不能长期住下来的事：身体出问题时找得到医生，孩子有学上，自己听得懂周围的人在说什么。

## 这一部分回答什么

- 我和家人有没有医保，看病的第一步去哪
- 冬天情绪低落怎么办，哪里有能说英语的心理支持
- 在这里结婚、生孩子要办哪些手续，能领哪些津贴
- 幼儿园怎么排队，不会立陶宛语的孩子怎么上学
- 读大学要多少钱，中国学历怎么认证
- 立陶宛语要学到什么程度
- 养老金以后能不能领，父母能不能接来
