# 医疗与就医入口

立陶宛的公共医疗靠强制医疗保险（PSD）运转。有保险的人看家庭医生、凭转诊看专科、住院、急救都不用付钱。难点有两个：弄清自己和家人到底有没有保险，以及接受「先找家庭医生」这条路径。

## 先确认有没有医保

**居留卡不等于医保。** 有没有保险取决于《健康保险法》第 6 条把你归在哪一类。

| 你的情况 | 有没有 PSD | 谁出钱 |
|---|---|---|
| 持临时居留许可、在立陶宛受雇工作（含蓝卡） | 有，从开始工作那天起 | 从工资里扣 6.98% |
| 上面这类人的未成年子女，本人持居留许可 | 有 | 国家出资（18 岁以下） |
| 上面这类人的配偶，本人持居留许可，自己也工作 | 有 | 从工资里扣 |
| 配偶不工作，但抚养 8 岁以下的孩子，或抚养两个以上未成年子女 | 有 | 国家出资（父母中的一方） |
| 配偶不工作，也不属于任何国家出资的类别 | 属于应参保人，**要自己缴** | 每月 80.48 欧元（2026 年） |
| 持学习类居留许可、不工作的留学生 | **没有** | 须自购商业医疗保险 |
| 留学生合法打工期间 | 有 | 从工资里扣 |
| 个体经营者 | 有，前提是按月缴费 | 自己缴，每月至少 80.48 欧元 |
| 工作满 6 个月后失业，并在就业服务局登记 | 有 | 国家出资 |
| 持永久居留许可 | 有，规则同公民 | 视就业状况 |

几个要点：

- **孩子的保险挂靠在父母身上。** 2023 年底法律修订后，在职居留许可持有人的未成年子女只要自己也有居留许可，就由国家出资参保。如果父母双方都没有雇佣关系（例如都以经商或学习为由居留），孩子不会自动有保险，需要向医保基金确认。
- **随居配偶最容易漏。** 持家庭团聚居留、不工作、孩子已满 8 岁且只有一个孩子的配偶，法律上是「应参保人」，必须自己每月向 Sodra 缴 PSD。不缴的期间没有保险，而且欠款会累积成债务，最多追溯五年。
- **国家出资不是自动生效的。** 例如「抚养 8 岁以下子女的父母一方」这个身份，按作者家的经验要自己去办理登记。拿到居留卡后查一下状态，没有保险就打医保基金或 Sodra 的电话，问清该去哪个窗口办。

**查询自己有没有保险**：在医保基金的公开查询页 [dpsdr.vlk.lt](https://dpsdr.vlk.lt/PublicSearch.aspx) 输入个人代码。全家人每个人都查一遍。

有疑问打医保基金电话 +370 5 232 2222，或 Sodra 电话 1883。

## 第一步：登记家庭医生

有保险之后，要主动去一家诊所登记（prisirašymas），选定一位家庭医生（šeimos gydytojas）。不登记就没有人给你开转诊单。

- **选哪家**：任何一家与医保基金签约的初级诊疗机构都行，不受住址限制。公立的叫 poliklinika，私立连锁也有签约的。对有保险的人，两者看家庭医生都免费。
- **带什么**：护照、居留卡、个人代码、联系方式。前台填一张申请表，十几分钟办完。孩子由父母代签。
- **费用**：登记手续费 0.29 欧元。登记不满六个月就换机构，收 2.90 欧元。
- **同时登记**：孩子登记儿科医生，全家顺带选定一家心理健康中心。

维尔纽斯常见的选择：

| 机构 | 性质 |
|---|---|
| Centro poliklinika | 市属公立，市中心 |
| Antakalnio poliklinika | 市属公立 |
| Karoliniškių poliklinika | 市属公立 |
| Šeškinės poliklinika | 市属公立 |
| InMedica | 私立连锁，可登记家庭医生 |

选的时候问一句医生会不会英语。公立诊所里年轻医生英语普遍可以，年长的医生可能只会立陶宛语和俄语。

## 看病的路径

```
身体不舒服
   │
   ├─ 危及生命 → 打 112 或直接去医院急诊
   │
   └─ 不紧急 → 约家庭医生
                  │
                  ├─ 家庭医生能处理 → 开药、开病假
                  │
                  └─ 需要专科 → 开转诊单（siuntimas）
                                   │
                                   └─ 自己在预约系统里选医院和时间
```

**约家庭医生**：在 [ipr.esveikata.lt](https://ipr.esveikata.lt/) 上约，或打诊所电话。通常几天内能约上，急的话当天打电话问有没有加号。很多诊所支持电话或视频问诊，续开慢性病药不用跑一趟。

**转诊单**：看专科、做 CT 或核磁，都要先有家庭医生的转诊单。

- 有效期最长 180 天，要在有效期内约上号。
- 你可以去任何一家签约机构，不限于医生推荐的那家。
- 在 ipr.esveikata.lt 上能看到各家医院各专科的最早可约时间，差别很大，多比较几家。

**不需要转诊单的情况**：

- 在自己登记的机构看牙医
- 在自己登记的心理健康中心看心理或精神科
- 看皮肤性病科
- 同一个问题的复诊，慢性病的长期随访

**等待时间**是这个体系最大的问题。热门专科（内分泌、消化、皮肤、某些影像检查）排一两个月很常见。应对办法有三个：在预约系统里换一家医院，自费去私立诊所，或者自费先看一次专科、再由那位医生开转诊做后续检查。最后这条路是合规的，前提是那家机构在该专科有医保合同。

**电子健康门户** [esveikata.lt](https://www.esveikata.lt/) 能看到自己的就诊记录、检查结果、电子处方和疫苗记录，父母可以代管孩子的账户。有手机 App。用银行、Smart-ID 等电子身份登录。

## 急不急，去哪

**危及生命**（胸痛、呼吸困难、意识不清、大出血、严重过敏、中风迹象）：打 **112**。接线员会说英语，救护车免费。

**需要当天处理但不致命**（骨折、伤口要缝、孩子高烧不退、剧烈腹痛）：直接去医院的急诊接诊部（priėmimo skyrius），24 小时开放。按病情分级，不重的要等几个小时。真正的急救对所有人免费，不看有没有保险。没有保险且不属于急救范围的，会收费。

**不急**：约家庭医生。晚上和周末，诊所会公布值班安排。

## 药

- **处方药**全部是电子处方。医生在系统里开，你拿居留卡或护照去任何一家药店取。
- **抗生素必须有处方**，药店不会通融。
- **药店连锁**：Eurovaistinė、Gintarinė vaistinė、Benu、Camelia，街上到处是。通宵营业的很少，全国只有几家，用连锁官网的门店查询筛「visą parą」（全天）。
- **报销药**：列入报销清单的药由医保付基准价，你付差价。药剂师有义务先推荐差价最低的那一种。一年内买这类药付的差价累计到 70.02 欧元后，超出部分由国家承担。
- **非处方药**（退烧、感冒、过敏、肠胃药）药店直接买，布洛芬和对乙酰氨基酚这里叫 ibuprofenas、paracetamolis。价格比国内贵。
- **从国内带药**：常用药可以随身带合理的自用量，最好保留原包装和说明书。含麻黄碱、可待因等成分的药在欧盟受管制，中成药成分复杂，过海关有不确定性。长期服用的处方药，带上英文的诊断和处方，落地后尽快让家庭医生接手续开。

## 牙科

牙科是公共医疗里覆盖最薄的一块。

- **成人**：在登记的签约机构看牙，医保只付医生的劳务，补牙材料、麻药、一次性用品要自己付。实际花费不低。
- **儿童**：材料也免费。恒磨牙的窝沟封闭免费，做到 14 岁。正畸有部分补偿。
- 大多数成年人直接去私立牙科诊所自费。洗牙、补牙、根管的价格低于西欧，高于国内。
- 带孩子的家庭，落地后尽早在登记的诊所约一次儿童牙科检查。

## 疫苗

**儿童**按国家免疫程序免费接种 14 种疾病的疫苗：结核、乙肝、百日咳、白喉、破伤风、b 型流感嗜血杆菌、脊髓灰质炎、麻疹、腮腺炎、风疹、肺炎球菌、HPV、轮状病毒、B 群脑膜炎球菌。2 到 7 岁的儿童可以免费打流感疫苗。

带孩子来的家庭，把国内的接种本翻译成英文带来。儿科医生会对照立陶宛的程序，给出补种计划。国内程序里有、这里没有的（如乙脑、甲肝、水痘），不需要处理。这里有、国内自费的（如肺炎球菌、轮状、B 群脑膜炎球菌），可以按年龄补。

**需要自费的**：水痘、甲肝、ACWY 群脑膜炎球菌，以及下面要说的蜱传脑炎。

### 蜱传脑炎疫苗

立陶宛是欧洲蜱传脑炎（erkinis encefalitas）发病率最高的国家之一，2025 年登记 642 例，2024 年 807 例。蜱虫不只在深山老林，城市公园和自家院子里也有。

- **强烈建议全家接种**，尤其是喜欢去森林和湖边的人，以及孩子。
- 基础免疫三针：第一、二针间隔 1 到 3 个月，第三针在第二针之后 5 到 12 个月。之后每 5 年加强一次，60 岁以上每 3 年。
- 想在夏天之前有保护，冬天或早春就要开始打。
- 国家只给 50 到 60 岁的人免费接种。其他人自费，每针大约二三十欧元，在登记的诊所或私立诊所都能打。
- 疫苗不防莱姆病。莱姆病同样由蜱虫传播，没有疫苗，每年登记一万五千多例。被咬之后的处理见[自然、户外与周边旅行](../rights/outdoors.md#蜱虫)。

**成人的其他疫苗**：流感疫苗对 65 岁以上、慢性病患者、孕妇免费，其他人自费，每年秋天在诊所或药店打。白喉破伤风建议每十年加强一次。

## 自费和商业保险

很多雇主提供商业医疗保险作为福利。它的用处是让你绕过等待：直接约私立诊所的专科、做检查、看牙、配眼镜，在额度内报销。入职时问清楚额度和覆盖项目。

没有商业保险时，私立诊所按次收费，看一次专科通常是几十到一百欧元，具体看各诊所的价目表。维尔纽斯常见的私立医疗机构有 InMedica、Northway、Affidea、Meliva、Baltijos-Amerikos klinika。

留学生和没有 PSD 的人，商业医疗保险是必需品，也是申请居留的条件。

## 语言

没有官方的英语医生名单，也没有成规模的中文就医资源。可行的做法：

- 预约时直接问「Ar gydytojas kalba angliškai?」（医生说英语吗）。
- 把症状、过敏史、正在吃的药用英语和立陶宛语写在手机里。
- 病历和检查报告是立陶宛语的，用翻译工具看得懂大意，重要的结论请医生用英语解释一遍。
- 复杂的病情可以带一位会立陶宛语的朋友，或者选私立诊所，那里的英语服务更有保障。

## 欧洲医保卡

有 PSD 的人可以申请欧洲医保卡（立陶宛语缩写 ESDK，英文 EHIC），在欧盟其他国家旅行时看急诊，按当地参保人的待遇。

- 在 [e.vlk.lt](https://e.vlk.lt/) 上申请，可以寄到快递柜。
- 首次办理免费，五个工作日内办好。遗失补办 15 欧元。
- 它不是旅行保险，不管医疗转运和私立医院。出远门仍然建议另买旅行险。

!!! question "待核实"

    欧洲医保卡对非欧盟国籍持卡人在个别国家（如丹麦）的适用有限制，出行前向医保基金确认。
