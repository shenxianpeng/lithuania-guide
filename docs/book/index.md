# 全书目录

全书分五部分、二十六章。前后有一条线索：先理解这个国家，再把日常生活搭起来，然后是人生里的大事，接着是钱，最后是出了问题找谁。

每章结尾都列出了官方入口和事实核验时间。

## 第一部分 认识立陶宛 { #foundations }

先知道自己在哪里。地图、历史、政府怎么运作、人和人怎么相处，以及这个国家在欧洲和世界里的位置。

1. [地理、气候与城市](foundations/geography.md)：比漠河还北的纬度，冬天下午四点天黑
2. [关键历史与社会形成](foundations/history.md)：两个独立日的由来，语言和国防为什么敏感
3. [国家制度与公共事务](foundations/government.md)：总统、议会、市政府各管什么，电子政务怎么用
4. [社会文化与默会知识](foundations/culture.md)：打招呼、做客、节假日、篮球
5. [立陶宛与世界](foundations/world.md)：欧盟、申根、北约，以及中立关系对日常的影响

## 第二部分 建立日常生活 { #life }

落地之后最先要处理的事：身份、住处、吃饭、出行、上网。

6. [身份、居留与行政](life/documents.md)：签证、居留许可、蓝卡、家庭团聚、申报住址、永居与入籍
7. [住房、租赁与购房](life/housing.md)：找房、合同、押金、冬天的暖气账单、买房
8. [衣食、购物与家庭运转](life/household.md)：超市、中国食材、网购、快递柜、垃圾分类
9. [交通、驾驶与出行](life/transport.md)：公交、火车、换驾照、买车、回国航线
10. [数字生活与通信](life/digital.md)：手机卡、宽带、Smart-ID、常用 App
11. [社区、文化与休闲](life/community.md)：图书馆、运动、周末去哪儿、华人社区

## 第三部分 健康、家庭与学习 { #people }

人生里更长线的事：身体、家人、孩子上学、学语言、变老。

12. [医疗与就医入口](people/health.md)：医保资格、家庭医生、专科、急诊、药店
13. [心理健康与无障碍](people/wellbeing.md)：冬季情绪、求助热线、残障服务
14. [婚姻、家庭与生育](people/family.md)：结婚登记、产假、育儿津贴、儿童金
15. [幼儿园与中小学](people/school.md)：报名、排位、教学语言、国际学校
16. [大学与终身学习](people/learning.md)：留学、学费、学历认证
17. [立陶宛语与语言生活](people/language.md)：要不要学，去哪学，考什么
18. [养老、父母与身后事](people/aging.md)：养老金、接父母、最后的手续

## 第四部分 工作、收入与财务 { #work }

钱从哪里来，交了多少税，剩下的怎么放。

19. [求职与职场文化](work/career.md)：招聘渠道、薪资水平、面试和办公室
20. [劳动关系与社会保障](work/employment.md)：合同、休假、病假、辞退、失业金
21. [银行、储蓄与保险](work/finance.md)：开户、支付、养老金支柱、保险
22. [个人税务与年度申报](work/tax.md)：税前到税后、税档、年度申报、跨境收入
23. [创业与经营](work/business.md)：个体经营、MB、UAB，税和合规

## 第五部分 法律、安全与户外 { #rights }

出了问题找谁，怎么保护自己，以及怎么享受这里的森林和湖。

24. [权利、纠纷与求助机构](rights/legal.md)：消费者权益、劳动争议、法律援助
25. [公共安全与应急](rights/safety.md)：112、诈骗、民防、日常容易违反的规定
26. [自然、户外与周边旅行](rights/outdoors.md)：国家公园、蜱虫、采蘑菇、波罗的海三国
