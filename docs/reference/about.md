# 阅读说明

## 这本指南是什么

一本用中文写的立陶宛生活参考书。它想解决两个问题：让你看懂这个社会是怎么运转的，以及在需要办事的时候找得到入口。

我住在立陶宛，中文世界里关于这里的系统资料很少，就写了这一本。章节框架参考了《[加拿大生活指南](https://ca.vonng.com/)》。

## 写给谁

- 已经拿到工作、准备搬来立陶宛的人
- 刚落地、正在一件件办手续的人
- 带着家人孩子一起来的人
- 在比较几个欧洲国家、还没决定的人
- 来留学的学生

正文不预设你的身份。但很多规则对中国公民和对欧盟公民不一样，凡是有差别的地方，默认讲的是**持中国护照、以工作或家庭团聚为由居留**的情况。

## 内容从哪来

初稿的资料检索和整理借助了 AI：由它逐项打开官方网站和法律原文核对数字和规则，记录来源和核对日期，再由作者审阅成文。没能在官方来源找到依据的内容，在正文里标成了「待核实」。

每一章的事实来自三类来源，可信程度不一样：

1. **法律和官方机构的网站**。移民局、税务局、社保局、医保基金、车管所、各市政府。涉及金额、期限、资格的内容都尽量追到这一层，并在章末给出链接。
2. **银行、会计师事务所、房产机构和主流媒体的公开资料**。主要用于房租、物价、利率这类没有官方定价的数字。这些数字给的是区间。
3. **生活经验**。哪家超市有什么、办事窗口实际怎么操作、本地人的习惯。这部分带有主观色彩，也最容易因人而异。

正文里会看到两种提示框：

!!! warning "注意"

    容易出错、出错后果比较重的地方。

!!! question "待核实"

    没能在官方来源找到明确说法，或者不同来源说法不一致。遇到这类内容，请自己向相关机构确认。

## 关于时效

- 每章末尾有**事实核验时间**。它表示那一章的数字和规则在那个月核对过，不代表之后没有变化。
- 立陶宛的最低工资、税档、社保缴费基数、各类津贴**每年 1 月 1 日调整**。居留政策这几年改得很频繁。
- 所有带年份的金额集中放在 [2026 年关键数字](numbers.md)里，每年更新一次。
