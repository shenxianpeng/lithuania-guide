## 每年更新这页时

1. 一月：最低月薪、平均工资（VDU）、BSI、税档金额、免税额公式、自缴医保、儿童金、失业金参数、公交票价。
2. 五月：移民规则用的平均工资（BDU）和由它算出的蓝卡门槛。
3. 随时：居留规费、配额、法律修订。
