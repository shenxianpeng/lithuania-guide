# 维尔纽斯

首都，约 61 万人，全国唯一还在增长的大城市。国际公司、政府机构、大学、国际学校大多在这里，在立陶宛的外国人也大多住在这里。对第一次来的中国人，维尔纽斯几乎是默认选项。

## 城市的样子

内里斯河穿城而过。南岸是老城，欧洲保存最大的巴洛克老城之一，世界遗产，石子路、教堂尖顶、庭院。北岸是新的商务区，玻璃幕墙的写字楼集中在 Konstitucijos 大街一带。

城市被森林和丘陵包着，绿化率很高，从市中心骑车二十分钟就能进林子。没有地铁，公交和无轨电车覆盖全城，高峰期主干道会堵。

离白俄罗斯边境只有三十公里左右，这是地理事实，日常生活中感觉不到。

## 住哪

| 区域 | 特点 | 适合 |
|---|---|---|
| **Senamiestis（老城）、Užupis** | 最有味道，餐厅酒吧多。老楼多，停车难，周末吵 | 单身、情侣、短期 |
| **Naujamiestis（新城）** | 紧邻老城，近年翻新很多，咖啡馆和创意产业集中 | 年轻上班族 |
| **Šnipiškės** | 北岸商务区，新公寓楼多，步行上班 | 在商务区工作的人 |
| **Žvėrynas** | 河湾里的老别墅区，安静，绿化好，房价高 | 预算宽裕的家庭 |
| **Antakalnis** | 沿河向东北延伸，靠近森林和大学，有好学校 | 家庭 |
| **Žirmūnai、Šeškinė、Fabijoniškės、Pašilaičiai、Justiniškės** | 北部和西北部的大型住宅区，苏联时期板楼和新楼混合，超市学校齐全，租金低 | 家庭、预算有限的人 |
| **Pilaitė、Perkūnkiemis、Bajorai** | 外围的新建小区，房子新，带车位，离市中心远 | 有车的家庭 |
| **Lazdynai、Karoliniškės** | 西部的老住宅区，绿化好，楼龄老 | 预算有限的人 |
| **Naujoji Vilnia、Grigiškės** | 远郊，最便宜 | —— |

选区域时要看的三件事：到公司的通勤、幼儿园和学校的片区、楼有没有做过保温改造。

## 办事

| 事情 | 去哪 |
|---|---|
| 外国人综合咨询 | **International House Vilnius**，Konstitucijos pr. 3（市政府大楼）。移民局、税务局、Sodra、就业服务局的窗口在一处，英语服务 |
| 居留许可 | 移民局维尔纽斯客户服务点 Vytenio g. 18，在 MIGRIS 上预约。高技能人才、研究人员和教师、创业者、企业主及其家属，还有欧盟公民，也可以约市政府大楼 Konstitucijos pr. 3 的窗口 |
| 申报住址 | 所在的街道办（seniūnija），或线上 |
| 出生、结婚登记 | 民事登记处，K. Kalinausko g. 21 |
| 驾照考试 | 车管所维尔纽斯分部 |
| 幼儿园和学校报名 | [svietimas.vilnius.lt](https://svietimas.vilnius.lt/) |
| 市政服务总入口 | [paslaugos.vilnius.lt](https://paslaugos.vilnius.lt/en/) |

维尔纽斯市给本市居民的几项补贴，都以住址申报在维尔纽斯市为前提：

- 孩子上私立幼儿园，每月补贴 120 欧元。
- 免费的立陶宛语课程（Aš kalbu 项目）。

学生参加课外兴趣班每月补贴 25 欧元（NVŠ krepšelis），这一项不看住址，1 到 12 年级的学生都能用。

注意「维尔纽斯市」和「维尔纽斯区」是两个不同的自治市。住在城市外围的新小区，可能属于维尔纽斯区，适用的是另一套幼儿园、学校和补贴。

## 交通

- 票价和 App 见[交通、驾驶与出行](../book/life/transport.md#维尔纽斯)。
- 导航用 Trafi。
- 夏天骑车和电动滑板车很方便。冬天路面有冰雪，基本靠公交和步行。
- 停车分蓝、红、黄、绿四档收费区。住在收费区内的居民可以申请居民停车许可。

## 看病

- 市属的公立诊所有 Centro、Antakalnio、Karoliniškių、Šeškinės 等，私立连锁有 InMedica、Northway、Affidea 等。
- 最大的综合医院是 Santaros klinikos，在城北。
- 急诊地址见[医疗与就医入口](../book/people/health.md#急不急去哪)。

## 带孩子

- 国际学校集中在这里，见[幼儿园与中小学](../book/people/school.md#国际学校)。
- 新建住宅区的公立幼儿园名额通常最紧。
- 周末去处：Vingis 公园、Bernardinai 花园、能源与技术博物馆、电视塔、Belmontas 的磨坊和瀑布、特拉凯城堡（28 公里）。
- 夏天去绿湖（Žalieji ežerai）和 Balsys 湖游泳。
- 冬天有 Liepkalnis 滑雪场、室内滑冰场、室内游乐场。

## 吃和买

- 商场：Akropolis、Ozas、Panorama、Europa。
- 集市：Halės turgus、Kalvarijų turgus。
- 亚洲食品：Azija Panda（Konstitucijos pr. 12 和 Trakų g. 7）。
- 中餐、日料、韩餐、越南粉、格鲁吉亚菜都能找到。

## 周边

- **特拉凯**：湖中城堡，半天。
- **凯尔纳韦**：古都遗址，半天。
- **欧洲地理中心**：城北 26 公里处的一块纪念碑。不远处还有一个户外雕塑公园 Europos parkas。
- **Verkiai 和 Pavilniai 地区公园**：就在市区边上，徒步和观景。
- **Anykščiai**：树冠步道，一天。
- **德鲁斯基宁凯**：温泉和水上乐园，一个周末。

## 适合谁

- 第一次来立陶宛、主要靠英语工作和生活的人。
- 孩子要上国际学校的家庭。
- 想要最多的工作机会和社交选择的人。

代价是全国最高的房租和房价，以及早晚高峰的堵车。
