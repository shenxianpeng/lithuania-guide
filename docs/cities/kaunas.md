# 考纳斯

第二大城市，约 30 万人，位于国土正中，涅曼河与内里斯河在这里交汇。两次大战之间它是立陶宛的临时首都，留下了一整片现代主义建筑，2023 年列入世界遗产。今天它是大学城和工程制造业的中心。

## 一眼看懂

| | |
|---|---|
| 人口 | 约 30 万（2026 年初） |
| 平均税前月薪 | 2,741 欧元，到手约 1,658 欧元（2026 年第二季度） |
| 一室一厅月租 | 普通住宅区 380–630 欧元，市中心 450–900 欧元 |
| 公寓均价 | 每平方米 2,339 欧元（2026 年 9 月） |
| 公交 | 单次 0.70 欧元，每月封顶 28 欧元 |
| 机场 | 考纳斯机场，廉价航空为主 |
| 到维尔纽斯 | 火车 1 小时出头，每天最多 15 班 |
| 到海边 | 开车约 2 小时 |

和维尔纽斯比，工资低不到一成，房租低两成左右，房价低近三成。

## 城市的样子

老城在两河交汇的尖角上，红砖的城堡和市政厅广场。从老城向东是一条近两公里长的步行街 Laisvės alėja（自由大道），两边是两次大战之间建的银行、邮局、剧院、公寓楼，线条简洁，是世界遗产的核心。

城市比维尔纽斯紧凑，节奏更慢，本地人的比例更高。篮球是这里的城市信仰，Žalgiris 队的主场 Žalgirio arena 建在河心岛上。

## 工作

- **高校**：考纳斯理工大学（KTU）、维陶塔斯大公大学（VDU）、立陶宛健康科学大学（LSMU）。LSMU 的医学和牙医专业有大量国际学生。
- **制造和工程**：城郊的考纳斯自由经济区聚集了汽车电子等外资工厂。
- **IT**：有一批软件公司和外企的研发中心，规模比维尔纽斯小。
- **物流**：地处国土中心和两条主要高速公路的交点，机场旁边有货运枢纽。

英语岗位比维尔纽斯少，集中在高校、IT 和外资工厂。很多人住在考纳斯、每周去维尔纽斯上几天班，火车一小时出头，可行。

## 住哪

| 区域 | 特点 |
|---|---|
| **Centras（市中心）、Senamiestis（老城）** | 步行可达一切，现代主义老楼多，停车难 |
| **Žaliakalnis** | 中心区北侧的坡上，老别墅和橡树林公园，安静，有缆车连到市中心 |
| **Šilainiai、Eiguliai、Dainava、Kalniečiai** | 北部和东部的大型住宅区，板楼为主，生活设施齐全，租金低 |
| **Aleksotas、Freda** | 河南岸，独栋房多，靠近植物园 |
| **Romainiai、Giraitė 等西郊** | 新建的联排和独栋小区，要有车 |

## 办事

- **居留许可**：移民局考纳斯客户服务点（A. Juozapavičiaus pr. 57），在 MIGRIS 上预约。
- **幼儿园报名**：[idarzeli.kaunas.lt](https://idarzeli.kaunas.lt/)。
- **公交**：App 叫 Žiogas，规则见[交通、驾驶与出行](../book/life/transport.md#考纳斯)。
- **免费立陶宛语课**：VDU 面向非欧盟公民的免费课程就在考纳斯开，也有线上班。
- **移民信息中心 MiCenter** 有考纳斯的信息页面：[micenter.lt/en/kaunas](https://micenter.lt/en/kaunas)。

考纳斯没有像维尔纽斯的 International House 那样成规模的外国人一站式服务中心，办事更多要靠自己和雇主的 HR。

## 带孩子

- **立陶宛动物园**在这里，全国唯一的大型动物园。
- **Ąžuolynas 橡树林公园**：市区里的一大片古橡树林。
- **隆姆希什基斯露天博物馆**：城东二十公里，各地区的老农舍，谢肉节和复活节有活动。
- **考纳斯潟湖**（Kauno marios）：城东的水库，夏天游泳、划船、骑车。
- **第九堡垒**：沙俄时期的要塞，后来是纳粹的屠杀场，现在是博物馆。
- **魔鬼博物馆**：收藏了几千个魔鬼造型的雕塑和面具，孩子觉得有趣。
- 国际学校有，选择比维尔纽斯少。

## 吃和买

- 商场：Akropolis（市中心河边）、Mega（城北，里面有一个大型水族箱）。
- 老城和自由大道两侧餐厅咖啡馆很多，价格比维尔纽斯低一点。
- 亚洲食品店有几家，品种不如维尔纽斯全，可以网购。

## 适合谁

- 工程师、在外资工厂或高校工作的人。
- 来读医学和工科的留学生。
- 想要比维尔纽斯低的生活成本、能接受英语环境弱一些的人。
- 在维尔纽斯上班但可以部分远程的人。
