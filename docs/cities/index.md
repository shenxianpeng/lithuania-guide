# 按城市查

立陶宛是单一制国家。税法、劳动法、居留规则、医保、教育制度全国统一，不像联邦制国家那样每个地区一套规矩。

城市之间的差别在这些地方：

- **房租和房价**：维尔纽斯明显高于其他城市
- **工作机会**：国际公司和英语岗位大部分在维尔纽斯
- **公共交通**：各城市各有一套票务系统和 App
- **幼儿园和学校**：名额、报名系统、市政补贴由各市政府决定
- **市政服务**：停车、垃圾清运、供暖公司、针对外国人的服务中心
- **外国人的比例**：决定了英语好不好用

| | 维尔纽斯 | 考纳斯 | 克莱佩达 |
|---|---|---|---|
| 人口 | 约 61 万 | 约 30 万 | 约 16 万 |

| 英语通行度 | 高 | 中 | 中 |
| 机场 | 维尔纽斯机场 VNO | 考纳斯机场 KUN | 帕兰加机场 PLQ |
| 到海边 | 约 3.5 小时 | 约 2 小时 | 市内就有 |
| 适合 | 第一次来、英语工作、带孩子找国际学校 | 工程师、学生、想省房租 | 航运物流从业者、喜欢海 |
