# 创业

在立陶宛注册一家公司只要一个工作日。在那之前要想清楚的事，以及注册之后每个月要做的事，才是这页的重点。

## 第一步：确认身份允许

- [ ] **看自己的居留类别。**
    - 永久居留：不受限制。
    - 家庭团聚：有工作权。自营和当公司负责人是否涵盖，要问。
    - 蓝卡、普通雇佣：居留依据是那份雇佣。另做经营要问。
    - 学习类、毕业求职类：见[创业与经营](../book/work/business.md#你的居留身份允许吗)。
- [ ] **写信问移民局**（info@migracija.gov.lt），拿到书面答复：
    1. 我的居留类别是否允许登记个体经营？
    2. 是否允许作为成员或股东设立 MB 或 UAB？
    3. 是否允许担任公司负责人并取酬？
    4. 对下次续签有什么影响？
- [ ] **确认不动支撑全家居留的那份工作。** 拿到永久居留之前，不要为了创业辞职。

## 第二步：验证想法

- [ ] 用最便宜的方式验证有没有人愿意付钱，再谈注册。
- [ ] 了解行业的合规要求：需不需要牌照，产品要符合哪些欧盟规定，要不要登记增值税。
- [ ] 算清固定成本：会计费、社保、银行费用、地址费用。
- [ ] 定一条止损线：投入多少钱、多长时间没有起色就停。

## 第三步：选形式

| 你的情况 | 考虑 |
|---|---|
| 接私活、做咨询、副业，一个人 | 个体经营证明 |
| 清单内的小生意，或者出租房屋 | 营业执照 |
| 一到几个人的小公司，想要有限责任，成本压到最低 | MB |
| 要雇人、要融资、要对外显得正式 | UAB |

各种形式的税和社保见[创业与经营](../book/work/business.md#四种形式)。

- [ ] 找一位会英语的会计聊一次，带着这几个问题：
    1. 按我预计的收入，哪种形式总税负最低？
    2. 我每月的社保成本是多少？
    3. 新设小企业的零税率我符不符合条件？
    4. 什么时候登记增值税最合适？
    5. 记账服务每月多少钱？

## 第四步：注册

**个体经营**

- [ ] 在税务局的线上系统登记活动类别，当天生效。
- [ ] 之后可以开票收款。每年必须做年度申报，没收入也要报。

**MB 或 UAB**

- [ ] 办好合格电子签名（Mobile-ID）。没有的话走公证人。
- [ ] 在登记中心预留公司名称。
- [ ] 准备注册地址，取得产权人同意。
- [ ] 用标准章程在自助系统里生成设立文件并签名。MB 登记费 17.13 欧元，UAB 14.02 欧元。
- [ ] UAB 开资本金账户，存入至少 1,000 欧元。
- [ ] 提交，一个工作日内登记完成。

## 第五步：注册之后马上要做的

- [ ] **开公司银行账户。** 对非欧盟公民的新公司，这一步可能要几周。同时申请两三家。
- [ ] **签会计服务合同。**
- [ ] 在 Sodra 和税务局完成相应登记。要雇人的，登记为雇主。
- [ ] 需要的话登记增值税。年销售额超过 45,000 欧元必须登记。
- [ ] 进出口的，申请 EORI 号。
- [ ] 卖实物商品的，处理产品合规：欧盟境内责任人、标签、安全文件、包装回收义务。
- [ ] 买必要的保险。
- [ ] 个人账户和公司账户严格分开。

## 每个月、每年

- [ ] 每月把票据交给会计。
- [ ] 按期申报和缴纳：增值税、社保、雇员的个人所得税。
- [ ] 从公司取钱之前问会计怎么取。工资、MB 成员提款、股息的税负不一样。
- [ ] 每年提交财务报表和企业所得税申报。
- [ ] 每年做个人的年度所得税申报。
- [ ] 续签居留时，按移民局此前答复的要求准备经营相关的材料。

## 想靠公司拿居留的

那是另一条路，门槛高得多：公司实际经营 6 个月以上、雇有本地员工且工资合计不低于 2 倍全国平均工资、自有资本 28,000 欧元以上。或者走创业签证，要有创新性的项目。见[创业与经营](../book/work/business.md#靠公司拿居留)。

## 不做了

- [ ] 个体经营：在税务局注销登记，做完最后一年的申报。
- [ ] MB、UAB：正式清算程序要几个月，要结清税款和债务。零税率优惠要求三年内不停业，提前清算可能要补税。
- [ ] 不要把一家不经营的公司扔着不管。每年的申报义务还在，不报有罚款。
