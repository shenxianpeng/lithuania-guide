# 入职

在立陶宛开始一份新工作，要看懂的东西比国内多一层：合同、工资条上的各项扣款、社保和医保的状态，以及这份工作和你的居留之间的关系。

## 签合同之前

- [ ] **确认你的居留身份允许为这个雇主工作。**
    - 普通雇佣居留：拿到居留卡之后才能开始上班。换雇主要先获移民局许可。
    - 蓝卡：人已合法在立陶宛的，递交申请当天可以开始。头 12 个月换雇主要先获许可。
    - 家庭团聚、永久居留：没有限制。
    - 见[身份、居留与行政](../book/life/documents.md#换工作)。
- [ ] **看清工资数字是税前。** 到手大约是税前的六成。用 Sodra 的计算器算一下：[sodra.lt/skaiciuokles](https://sodra.lt/skaiciuokles/darbo-vietos-skaiciuokle)。
- [ ] 持蓝卡的，确认工资不低于门槛（2026 年是每月税前 3,617.10 欧元），并且会一直维持。
- [ ] 问清楚福利：商业医疗保险的额度和覆盖范围、年假天数、远程办公政策、搬迁补贴、语言课报销、子女学费。
- [ ] 问清楚雇主是否协助办理居留续签，费用谁出。

## 签合同时

- [ ] 合同应当有你看得懂的语言版本。两个版本内容要一致。
- [ ] 核对：岗位名称、工作地点、工资、工时、合同期限、试用期长度。
- [ ] **试用期最长 3 个月。** 期间任何一方提前 3 个工作日通知就能解除。
- [ ] 竞业限制、保密、知识产权条款看一遍。竞业限制要有补偿才有效。
- [ ] 留一份双方签字的合同原件或电子签名的 PDF。

## 入职第一周

- [ ] **提交免税额（NPD）申请。** HR 通常会给你一张表。不交的话每月多扣税，要等次年申报才能退。
- [ ] **提供银行账号**（LT 开头的 IBAN）。工资每月发一到两次。
- [ ] **第二支柱养老金**：2026 年起不再自动加入。要不要参加自己决定，见[银行、储蓄与保险](../book/work/finance.md#养老金三支柱)。
- [ ] 激活商业医疗保险，下载保险公司的 App。
- [ ] 完成入职的安全培训（法定要求）。
- [ ] 需要居留续签或换雇主许可的，和 HR 对一下担保函的时间表。

## 拿到第一张工资条

工资条（algalapis）上的主要项目：

| 立陶宛语 | 意思 |
|---|---|
| Priskaityta / Bruto | 应发（税前） |
| GPM | 个人所得税，20% |
| VSD | 社会保险（养老、疾病、生育），12.52% |
| PSD | 强制医保，6.98% |
| NPD | 当月适用的免税额 |
| Papildomas pensijų kaupimas | 第二支柱养老金，3%（参加了才有） |
| Išmokėta / Neto | 实发（到手） |

- [ ] 核对到手金额和你算的是否一致。
- [ ] 看免税额有没有用上。月薪超过 2,677 欧元的，免税额是零，这是正常的。
- [ ] 看有没有被扣第二支柱的 3%。你没有主动签约却被扣了的，问 HR。

## 入职一个月后

- [ ] **查医保状态**：[dpsdr.vlk.lt](https://dpsdr.vlk.lt/PublicSearch.aspx)。开始工作后你和未成年子女应该显示为有保险。
- [ ] **查 Sodra 记录**：登录 Sodra 个人账户，确认雇主已登记你的雇佣关系并在缴费。
- [ ] 还没登记家庭医生的，去登记。
- [ ] 了解公司的病假流程：生病当天通知谁，头两天公司付多少比例。

## 你有的权利

入职时不一定有人告诉你，但法律上都有：

- 每年至少 20 个工作日的年假。
- 有 12 岁以下的孩子：每三个月或每月有额外的带薪休息日。
- 有 8 岁以下的孩子：申请远程办公，雇主原则上要同意。
- 加班至少 1.5 倍工资，休息日和节假日 2 倍。
- 病假头两天雇主付，第三天起 Sodra 付。

见[劳动关系与社会保障](../book/work/employment.md)。

## 试用期里

- 把工作成果和收到的反馈留下书面记录。
- 手里保持三到六个月的生活费。
- 知道万一试用期没过，居留的时间线是怎样的。见[失业](job-loss.md)。
