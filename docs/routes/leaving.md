# 离开立陶宛

回国，或者去另一个国家。离开时把手续办干净，一是避免几年后收到欠税或欠费的通知，二是把属于你的钱拿回来。

## 离开前 2 到 3 个月

- [ ] **确定离职日期，按通知期书面辞职。** 普通辞职提前 20 个日历日。
- [ ] **按合同通知房东。** 约好交房日期和押金退还方式。
- [ ] **决定第二支柱养老金怎么办。** 2027 年 12 月 31 日前可以选择退出，拿回自己缴的部分和收益，免个人所得税。向养老基金公司申请，钱在下一季度初到账，所以要留出时间。见[银行、储蓄与保险](../book/work/finance.md#养老金三支柱)。
- [ ] **处理投资账户。** 不再是立陶宛税务居民时，投资账户视同关闭并计税。提前算一下。
- [ ] 孩子在上学的，向学校要成绩单和在读证明，办英文版。问清转学需要的文件。
- [ ] 要一份孩子的疫苗接种记录。
- [ ] 把全家的病历、检查结果从 esveikata.lt 上下载下来。
- [ ] 有车的，卖掉或办理出口。
- [ ] 开始处理家具和大件，在二手平台上卖或送人。

## 离开前 1 个月

- [ ] **税务：提交最终离境者的所得税申报表。** 年中永久离开的税务居民，要在离境前申报并缴清当年截至离境日的税。见[个人税务与年度申报](../book/work/tax.md#离开立陶宛时)。找会计帮忙办一次是值得的。
- [ ] 登记了个体经营的，注销。有公司的，决定是清算、转让还是保留。
- [ ] 解约或转让：宽带、手机合约、供电合同、健身房、保险、各种订阅。有合约期的问清违约金。
- [ ] 向雇主要：离职证明、收入证明、工作推荐信。回国或去别的国家找工作、办贷款时用得上。
- [ ] 申请一份 Sodra 的缴费记录证明。以后在其他欧盟国家工作或退休时，证明你在立陶宛的社保年限。
- [ ] 有贷款、分期的，结清。
- [ ] 查一下有没有未缴的罚单、欠费。

## 最后一周

- [ ] **交房。** 对照交房清单检查，记表读数，拍照，签交还确认，还钥匙。
- [ ] **申报离境。** 在街道办或线上办理住址注销（išvykimo deklaravimas）。
- [ ] 结清最后的杂费，和房东约定晚到的账单怎么结。
- [ ] 确认最后一笔工资、未休年假补偿已到账。
- [ ] 把预付费卡里的余额用掉。
- [ ] 把快递柜、网购的在途包裹处理完。

## 银行账户：先别关

- [ ] **至少保留一个账户到下一年的年中。** 退税、押金、Sodra 的款项、第二支柱的退出款都可能在你离开后才到账。
- [ ] 把联系邮箱和手机号改成离开后还能用的。
- [ ] Smart-ID 在离开后一段时间内还能用，前提是手机号和设备不变。居留许可失效后银行可能要求你更新身份信息或关闭账户，提前问清楚。
- [ ] 钱都到齐之后，把余额转走，再销户。

## 居留许可

- 居留依据消失后（不再工作、不再学习），许可会被撤销。离开前在 MIGRIS 里把情况变化通知移民局，并问清居留卡要不要交还。
- **申报了离境、或者离开时间超过允许的上限，永久居留许可会失效。** 持永居的人离开前务必弄清保留身份的条件。按《居住地申报法》，离开立陶宛超过 6 个月要申报离境，而申报离境会让永居失效（《外国人法律地位法》第 56 条），打算保留永居的，离开前先写信问移民局。
- 打算以后回来的，留好所有居留卡的复印件、Sodra 记录、税务记录。以后申请永居或入籍时，证明曾经的居住历史。

## 养老金

- **第一支柱**：缴费没有退还的途径。缴满 15 年的，到 65 岁可以申请，养老金可以汇到国外。不满 15 年的，如果之后在其他欧盟国家工作，年限可以合并计算。见[养老、父母与身后事](../book/people/aging.md#养老金)。
- **第二支柱**：见上，2027 年底前可以退出。
- **第三支柱**：按合同条款处理，提前赎回可能有税务影响。

## 离开之后

- [ ] **次年 5 月 1 日前**，做离开那一年的年度所得税申报。可以在境外线上办，前提是 Smart-ID 或网银登录还能用。有退税的会退到你保留的立陶宛账户。
- [ ] 回到中国的：重新成为中国税务居民，国内的社保、医保、户口相关事项按当地规定恢复。
- [ ] 去另一个欧盟国家的：在新国家重新走一遍抵达流程。立陶宛的社保年限、蓝卡持有时间可以带过去。
- [ ] 留意立陶宛邮箱和账户里的通知，至少一年。

## 带什么走，留什么

- **带走的文件**：劳动合同和离职证明、全部工资条或年度收入证明、Sodra 缴费记录、税务申报记录、租房合同、孩子的出生记录摘录和学校文件、病历和疫苗记录、驾照。
- **电子版**：全部扫描一份放云端。
- 立陶宛驾照在欧盟内通用。回中国不能直接用，要按国内规定换领。
