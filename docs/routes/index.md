# 按事情查

正文是按主题分章的，但生活里的事会同时牵扯好几章。搬一次家，要改申报地址、换家庭医生的诊所、转幼儿园、通知银行和雇主。

这一部分把常见的九件事各写成一页清单。每一步只说做什么、找谁、期限多久，细节链接回正文。

| 事情 | 一句话 |
|---|---|
| [出发前](before-you-go.md) | 签证、文件认证、带什么、不用带什么 |
| [抵达头 30 天](arrival.md) | 把居留卡、住址、银行、手机、医生接起来 |
| [搬家](moving.md) | 不要只改一个地址 |
| [入职](start-work.md) | 合同、工资条、税和社保怎么看 |
| [失业](job-loss.md) | 居留、失业金和医保，哪个先处理 |
| [生病](illness.md) | 急不急，找谁，病假怎么开 |
| [生育](parenthood.md) | 从产检到孩子拿到居留卡 |
| [创业](business.md) | 先确认身份允许，再选公司形式 |
| [离开立陶宛](leaving.md) | 注销、退税、养老金和银行账户 |

## 怎么用这些清单

- 清单按**时间顺序**排列，有先后依赖的步骤会注明。
- 标了期限的步骤，期限来自法律规定。没标的是建议顺序。
- 每个人的身份不同，不是每一步都适用。持蓝卡的人、家属、学生、欧盟公民走的流程有差别，差别处会单独说明。
