# 搬家

在立陶宛，你的申报住址连着一串东西：幼儿园和学校的片区、官方信件的送达地址、不动产税的认定、换驾照时对常住的判断。搬家时只把箱子搬过去是不够的。

## 搬之前

- [ ] **按合同通知旧房东。** 书面通知，注意通知期。见[住房、租赁与购房](../book/life/housing.md#搬出)。
- [ ] **确认新房可以申报住址**，并写进新合同。
- [ ] 跨城市搬家的，先了解新城市的幼儿园和学校有没有名额。学年中间转学要直接联系新城市的教育局。
- [ ] 订搬家车。找搬家工人可以通过 Facebook 本地群组或分类信息网站，按小时计费。
- [ ] 提前两周联系宽带运营商办理移机或解约。有合约期的解约可能有违约金，移机通常免费。

## 搬的那几天

- [ ] **旧房**：和房东一起对照入住时的交房清单检查，记录水、电、气表的读数，拍照，签一份交还确认。交还所有钥匙。约定押金退还的时间和账户。
- [ ] **新房**：同样做交房清单，记读数，把现有的损坏逐一拍照发给新房东。
- [ ] 结清旧房最后一期的杂费。有的账单晚一个月才出，和房东说好怎么结。

## 搬完之后

**两周内**

- [ ] **重新申报住址。** 在新地址申报后，旧地址的申报自动失效。在街道办办理，需要新房东同意或者租赁合同。维尔纽斯不接受外国人线上申报。全家每个人都办。
- [ ] 2026 年 5 月起，住址变更不用再单独通知移民局，各机构之间自动获取。
- [ ] **通知雇主**新地址。
- [ ] **银行**：在网银里更新地址。
- [ ] **供电**：电表合同在你名下的，办理过户或迁移。
- [ ] **宽带、手机运营商**：更新账单地址。

**一个月内**

- [ ] **家庭医生**：新家离原来的诊所远的话，换一家近的。登记不满六个月就换，手续费是 2.90 欧元，满六个月是 0.29 欧元。在新诊所办登记就行，病历由新诊所去调。
- [ ] **幼儿园和学校**：跨片区或跨城市的，办理转园转学。
- [ ] **儿童金等福利**：跨城市搬家的，福利由新城市的市政府接手发放，在 spis.lt 上更新信息或联系市政府。
- [ ] **课外班补贴**：跨城市的要重新办。
- [ ] **车辆**：住在收费停车区的，向新城市的市政府申请居民停车许可，旧的作废。
- [ ] **各种会员、订阅、网购的默认快递柜**：改成新家附近的。
- [ ] **保险**：房屋或租客保险改到新地址。

## 买了房搬进去的

- [ ] 产权登记完成后，**把住址申报到自己的房子里**。2026 年起的不动产税，主要自住房的免税额以业主本人是否在这里申报住址为准。见[个人税务与年度申报](../book/work/tax.md#不动产税)。
- [ ] 加入楼栋的业主协会，进楼栋的群。
- [ ] 把水、电、气、暖、物业的账户都过户到自己名下。
- [ ] 买房屋保险。有房贷的银行会要求。
