# 生育

在立陶宛生孩子，医疗上的安排不复杂，复杂的是孩子出生后三个月内要办完的一串证件：出生登记、中国旅行证件、居留许可。这页按时间顺序列出每一步。

## 怀孕之前或刚发现怀孕

- [ ] **确认准妈妈有没有医保。**
    - 在工作：有。
    - 不工作，已有 8 岁以下的孩子或两个以上未成年子女：国家出资，有。
    - 不工作、第一胎：孕满 28 周之前**要自己每月缴 80.48 欧元**，否则孕早中期没有保险。
    - 在 [dpsdr.vlk.lt](https://dpsdr.vlk.lt/PublicSearch.aspx) 查。见[医疗与就医入口](../book/people/health.md#先确认有没有医保)。
- [ ] **算一下津贴资格。** Sodra 的产假和育儿假津贴要求休假前 24 个月内缴满 12 个月生育保险。来立陶宛不满一年就生的，领不到这部分，只能申请每月 444 欧元的育儿给付。
- [ ] **看一下护照和居留卡的有效期。** 避免在孕晚期和孩子刚出生时赶上续签。

## 孕期

- [ ] 在登记的诊所建档，开始产检。
- [ ] 孕妇可以免费打流感疫苗。
- [ ] 上班的准妈妈告知雇主。孕妇受解雇保护，可以要求调整工作条件，有权申请远程办公。
- [ ] 选产院，去参观，上孕妇课程。有医保的可以选任何一家签约医院。
- [ ] 想指定医生或助产士全程陪产的，提前联系并付费。见[婚姻、家庭与生育](../book/people/family.md#分娩)。
- [ ] **孕 30 周左右开始休产假。** 产前 70 天、产后 56 天，共 126 天。医生开具产假证明，向 Sodra 申请产假津贴（工资的 77.58%）。

## 孕晚期：把证件的路问清楚

- [ ] **联系中国驻拉脱维亚使馆**（在立中国公民的领事证件业务由其代管），问清在立陶宛出生的孩子办理护照或旅行证的流程、材料、时间，以及是否需要本人到场。电话 +371 26189539，邮箱 riga@csm.mfa.gov.cn。
- [ ] **准备结婚证的公证书、Apostille 和立陶宛语译文。** 出生登记要用。手头没有的，让国内家人现在就去办。
- [ ] 想好孩子的名字，包括拼音拼写。立陶宛的出生记录按护照上的拉丁字母拼写登记。
- [ ] 准备待产包。产院会给清单。

## 出生后第 1 周

- [ ] 医院出具出生医学证明，数据进入电子系统。
- [ ] 新生儿在医院接种乙肝疫苗和卡介苗，做新生儿筛查。
- [ ] 爸爸可以开始休陪产假：30 个日历日，可分两段，孩子满一岁前休完，津贴 77.58%。
- [ ] 出院后，诊所的儿科医生或护士会上门或约你带孩子去检查。

## 出生后 1 个月内

- [ ] **出生登记。** 法定期限是 3 个月，但后面的手续都等着它，尽快办。
    - 到民事登记处，或用电子身份在线上办。
    - 带父母的护照、居留卡、结婚证的公证书加 Apostille 加译文。
    - 办完孩子就有了**个人代码**。
    - 申请出生记录摘录，要多语种或英文版本，多要两份。
- [ ] **申请中国护照或旅行证。** 「中国领事」App 不接受从立陶宛提交，要联系驻拉脱维亚使馆走线下办理，做好带孩子去一趟里加的准备。
- [ ] **申报孩子的住址。**
- [ ] **确认孩子的医保**，给孩子登记儿科医生。
- [ ] **申请儿童金。** 在 [spis.lt](https://www.spis.lt/) 上办。每月 129.5 欧元。孩子要有居留证件，拿到之后补交，可以追溯补发。

## 出生后 3 个月内

- [ ] **向移民局为孩子申请居留许可。** 这是法定期限。孩子拿到和父母同类型、同有效期的许可。在 MIGRIS 填表、预约。
- [ ] 中国证件还没下来的，**在期限之前写信给移民局**说明情况，问清怎么处理，保留往来邮件。

!!! warning "不要拖"

    三件事环环相扣：出生登记 → 中国证件 → 居留许可。中间那一环现在要跨国办理，是最不确定的。孩子出生的第一周就启动。

## 产假结束后

- [ ] **选育儿假方案**并向 Sodra 申请育儿假津贴：
    - 领到 18 个月：工资的 60%。
    - 领到 24 个月：第一年 45%，第二年 30%。
    - 父母各有 2 个月不可转让，这两个月是 78%。
- [ ] 书面通知雇主休育儿假的起止时间。假期最长可以到孩子三岁。
- [ ] **持工作类居留的人休育儿假期间，确认居留怎么续。** 蓝卡对育儿假期间达不到工资门槛有 12 个月的容忍期。居留卡在育儿假期间到期的，提前问移民局续签要什么材料。
- [ ] 按儿童免疫程序带孩子打疫苗。2、4、6 个月各有一轮。

## 孩子一岁半到两岁

- [ ] **报幼儿园。** 公立园一般从一岁半或两岁开始收，热门的园要提前很久排。孩子一有个人代码和住址申报就可以在系统里登记。见[幼儿园与中小学](../book/people/school.md#幼儿园)。
- [ ] 回去上班。有 12 岁以下的孩子（2027 年起是 14 岁以下），每三个月有一天额外的带薪休息日；有 8 岁以下的孩子，可以申请远程办公。
- [ ] 请了正规保姆、孩子不上幼儿园的，可以申请每月 384.8 欧元的保姆补偿。

## 能拿到的钱，汇总

| 项目 | 金额 | 找谁 |
|---|---|---|
| 产假津贴 | 工资的 77.58%，126 天 | Sodra |
| 陪产假津贴 | 工资的 77.58%，30 天 | Sodra |
| 育儿假津贴 | 60%，或 45% 再 30% | Sodra |
| 儿童金 | 每月 129.5 欧元，到 18 岁 | 市政府（spis.lt） |
| 没有缴费记录时的育儿给付 | 每月 444 欧元，到 2 岁 | 市政府（spis.lt） |
| 一次性生育补助 1,036 欧元 | **持临时居留的中国公民领不到** | —— |
