# 抵达头 30 天

落地后的手续有先后依赖：没有居留卡开不了银行账户，没有银行账户拿不到 Smart-ID，没有 Smart-ID 登录不了政府网站。按下面的顺序走，能少跑很多冤枉路。

```
居留卡（个人代码）
   ├─→ 申报住址 ─→ 幼儿园、学校报名
   ├─→ 银行账户 ─→ Smart-ID ─→ 各种线上服务
   ├─→ 手机合约
   └─→ 开始工作 ─→ 医保生效 ─→ 登记家庭医生
```

## 第 1 天到第 3 天

- [ ] **买一张预付费手机卡。** 机场便利店或超市就有，几欧元。90 天内要用护照做实名验证。见[数字生活与通信](../book/life/digital.md#手机卡)。
- [ ] **公交直接刷银行卡**，上车在验票机上刷国内带来的 Visa 或 Mastercard。装上 Trafi 和 Bolt。
- [ ] **住进临时住处。** 先订两到四周的短租。
- [ ] **打开手机的紧急警报设置**，把立陶宛的卡放在主卡槽。见[公共安全与应急](../book/rights/safety.md#警报)。
- [ ] 把 112 和最近的急诊地址存进手机。
- [ ] 入境到医保生效之间靠旅行医疗保险，确认保单在有效期内。

## 第 1 周

- [ ] **去移民局办理居留手续。** 在境外已获批的，预约取居留卡。入境后才递交的，按 MIGRIS 里的预约去采集生物信息。见[身份、居留与行政](../book/life/documents.md)。
- [ ] **和雇主确认入职日期。** 普通雇佣居留要拿到居留卡之后才能开始工作；蓝卡持有人合法在境内的，递交申请当天就可以开始。
- [ ] **开始找长租房。** 看房时问清三件事：能不能申报住址，冬天的杂费多少，押金怎么退。见[住房、租赁与购房](../book/life/housing.md)。
- [ ] 去一趟 **International House Vilnius**（住在维尔纽斯的话）。移民局、税务局、Sodra、就业服务局在那里有咨询窗口，英语服务，可以把手头的疑问一次问完。

## 第 2 周到第 3 周

- [ ] **拿到居留卡。** 核对卡上的姓名拼写、出生日期、有效期。卡上的 11 位数字是你的个人代码。
- [ ] **签租房合同**，写明房东同意申报住址。交房时拍照录像，记下表读数。
- [ ] **申报住址。** 拿到居留卡后一个月内，在街道办或线上办。全家每个人都要申报。
- [ ] **开银行账户。** 带护照、居留卡、租房合同、劳动合同。把 IBAN 账号告诉雇主的 HR。见[银行、储蓄与保险](../book/work/finance.md#开户)。
- [ ] **激活 Smart-ID。** 通过银行办。之后登录政府网站、签文件都靠它。
- [ ] **签劳动合同、入职。** 向雇主提交免税额（NPD）申请。见[入职](start-work.md)。

## 第 3 周到第 4 周

- [ ] **确认医保状态。** 在 [dpsdr.vlk.lt](https://dpsdr.vlk.lt/PublicSearch.aspx) 输入个人代码查，全家每个人都查。不工作的配偶看自己属于哪一类，要不要自缴。见[医疗与就医入口](../book/people/health.md#先确认有没有医保)。
- [ ] **登记家庭医生。** 全家在同一家诊所登记，孩子登记儿科医生。带上孩子的疫苗本（英文翻译件）。
- [ ] **给孩子报幼儿园或学校。** 在市政府的教育报名系统里办，或直接联系市教育局。带孩子去做入园入学体检。见[幼儿园与中小学](../book/people/school.md)。
- [ ] **申请儿童金。** 在 [spis.lt](https://www.spis.lt/) 上办，孩子要有居留证件。见[婚姻、家庭与生育](../book/people/family.md#儿童金)。
- [ ] **把预付费卡换成合约**（可选），月费更低。
- [ ] **装宽带。**
- [ ] 办各家超市的会员卡。

## 第 2 个月

- [ ] **开始学立陶宛语。** 查一下所在城市的免费课程什么时候开放报名。见[立陶宛语与语言生活](../book/people/language.md)。
- [ ] **打蜱传脑炎疫苗**第一针（春夏季之前）。
- [ ] **处理驾照。** 需要开车的，预约体检和急救课，报名理论考试。见[交通、驾驶与出行](../book/life/transport.md#中国驾照)。
- [ ] 在 MIGRIS 里**订阅居留到期提醒**，把到期日和护照到期日记进日历。
- [ ] 登录一次 Sodra 和税务局的个人账户，确认雇主已经给你登记、在正常缴费。
- [ ] 家里备好 72 小时的应急物资，查一下最近的掩蔽所。
- [ ] 买一份租客财产和责任险（可选）。

## 容易漏的

- **配偶的医保。** 随居、不工作的配偶可能要自己每月缴，不缴会累积成欠款。
- **孩子的住址申报。** 幼儿园排位以此为准。
- **免税额申请。** 不交这张表，每个月多扣税。
- **国内的手机号。** 确认在这边能收到国内银行的验证短信。
- **试用期。** 头三个月雇主可以三天通知解除合同，手里留够应急的钱。
