# 出发前

从拿到 offer 或录取通知，到登上飞机，中间通常有两到四个月。这段时间里有几件事只能在国内办，到了立陶宛再补会非常麻烦。

## 时间线

### 确定要来之后（提前 3 到 4 个月）

- [ ] **确认自己的居留类别和递交地点。** 蓝卡、家庭团聚、留学可以在第三国的 VFS 网点递交，普通雇佣不行。中国境内没有受理点。2026 年 11 月 1 日起，要在立陶宛境内递交普通雇佣或本科学习类申请，必须已持立陶宛居留许可、立陶宛 D 签或其他申根国家的居留许可，持申根短期签证入境的不能再递交；蓝卡不受影响。见[从中国递交申请](../book/life/documents.md#从中国递交申请)。
- [ ] **检查护照有效期。** 最好剩余三年以上。居留许可的有效期不会超过护照有效期减三个月，而在立陶宛换护照要通过驻拉脱维亚使馆办理，周期长。有效期不足的话，出发前在国内换掉。
- [ ] **办文件的公证和 Apostille。** 中国文件在立陶宛使用只需附加证明书，不用领事认证。每样办两到三份：
    - 结婚证公证书
    - 孩子的出生医学证明公证书
    - 最高学历的毕业证和学位证公证书
    - 无犯罪记录证明（按移民局对你的类别的要求）
- [ ] **学历认证。** 申请蓝卡时，不受规管的职业只需雇主出具你具备高等专业资格的说明；医生、律师这类受规管的职业要先经主管机构认可。SKVC 的学历认可只受理已持立陶宛居留许可的人、欧盟公民等几类人的个人申请，人还在国内时由雇主去申请，耗时一个月左右。问雇主的 HR 要不要做、谁来做。
- [ ] 雇主或学校在 MIGRIS 提交担保函之后，你在 MIGRIS 填写申请并预约递交。

### 等结果的时候（提前 1 到 2 个月）

- [ ] **处理国内的手机号。** 国内银行、支付宝、微信、12306、各种政务 App 都靠短信验证码。把手机号改成最低月租的保号套餐，开通国际漫游收短信，并确认在国外能收到。这一条不做，出国后会处处卡住。
- [ ] **处理国内的银行卡。** 留一两张常用的借记卡，开通手机银行和境外使用。办一张 Visa 或 Mastercard 的信用卡或借记卡，刚到的头几周本地账户还没开下来，要靠它过渡。银联卡在立陶宛基本刷不了。
- [ ] **确认微信和支付宝已实名**，并绑定了不会注销的银行卡。
- [ ] **社保、公积金、个税。** 问清楚离职后社保怎么处理、公积金能否提取。在国内还有收入的话，了解一下税务居民身份的问题，见[个人税务与年度申报](../book/work/tax.md)。
- [ ] **体检和看牙。** 全家做一次体检，把牙齿的问题在国内处理完。立陶宛成人看牙基本自费，价格比国内高。
- [ ] **配眼镜。** 多配一副备用，这里配镜贵而且慢。
- [ ] **孩子的疫苗本**翻译成英文。到了之后儿科医生要对照补种。
- [ ] **孩子的在读证明和成绩单**，办公证或让学校出具英文版，入学时可能用到。
- [ ] **驾照。** 中国驾照在立陶宛不能直接换，要重新考理论和路考。带上驾照原件，并在国内办一份驾照公证翻译，路上租车和以后换证都可能用到。见[交通、驾驶与出行](../book/life/transport.md)。
- [ ] **找住处。** 先订两到四周的短租或服务式公寓，落地后再实地看长租房。不要隔着屏幕付长租押金。见[住房、租赁与购房](../book/life/housing.md)。

### 出发前一两周

- [ ] 买一份覆盖头一两个月的旅行医疗保险。入境后到正式开始工作、医保生效之间有空档。
- [ ] 换一些欧元现金，够头几天用就行，五百欧元以内。立陶宛几乎所有地方都能刷卡。
- [ ] 把所有重要文件扫描一份放在云端，另打印一份随身带。
- [ ] 把雇主 HR、房东、接机人的电话记在纸上。
- [ ] 下载离线地图和翻译 App，立陶宛语的离线语言包提前下好。

## 带什么

**值得带的**

- **文件原件**：护照、公证书和 Apostille、学历证书、驾照、疫苗本、病历。放随身行李。
- **常用药**：自己和孩子吃惯的感冒药、退烧药、肠胃药、过敏药，带两三个月的量，保留原包装。长期服用的处方药带上英文诊断证明。
- **转换插头**：立陶宛用欧标两圆脚插座，电压 230 伏。国内的电器电压没问题，但插头要转换。带两三个转换头和一个国标插线板。
- **电饭煲**：这里买得到，但选择少、价格高。小型的值得带一个。
- **调料和干货**：火锅底料、花椒、豆瓣酱、干辣椒、香菇、木耳。本地亚洲超市有基本的酱油醋，种类有限。肉制品和奶制品不能带入欧盟，含牛油的火锅底料、肉松、腊肠、月饼里的蛋黄都算，被查到会没收。
- **冬天的贴身保暖衣物**：秋衣秋裤、羊毛袜。外套和靴子可以到了再买，本地卖的更适合本地气候。
- **眼镜、隐形眼镜和护理液**。
- **孩子熟悉的东西**：几本中文书、常玩的玩具。搬家对孩子是很大的变化。
- **针线包、指甲刀、挖耳勺、筷子、菜刀**这类用惯了的小东西。中式菜刀要托运。

**不用带的**

- 大件厚重的被褥，本地 IKEA 和 JYSK 都有。
- 大量日用品，洗发水牙膏这里都有，价格差不多。
- 厚重的羽绒服如果占地方可以不带，十月开始本地商场有大量冬装。
- 大量现金。
- 国内的手机不用换，只要没有网络锁就能直接插本地卡。

## 心理准备

- **头三个月是最难的。** 手续一件套一件，语言不通，天气在变暗。这是所有人都经历的阶段，不代表你做错了决定。
- **如果是秋冬季到达**，要有准备：下午四点天黑，可能连续两周见不到太阳。尽量在春夏季搬来，给自己一个缓冲。
- **带孩子的家庭**，提前和孩子讲清楚要去哪里、为什么去、什么会变、什么不会变。
- **伴侣随行的**，提前谈一谈对方到了以后做什么。随居配偶有工作权，但找到工作需要时间，头一年往往是家里最孤单的那个人。
